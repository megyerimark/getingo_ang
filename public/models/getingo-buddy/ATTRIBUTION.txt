GETINGO BUDDY MODEL PLACEHOLDER
==============================

Production model path:
/public/models/getingo-buddy/getingo-buddy.glb

The application no longer downloads a third-party fallback model. If the local GLB is
missing, the frontend builds a simple Getingo cat from Three.js primitives, so no external
model request is made.

If you later choose to use a third-party GLB, keep the license and attribution required by
that model next to the deployed asset. Do not copy the old demo attribution unless that
specific licensed model is actually used.
